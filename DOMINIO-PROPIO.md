# Dominio propio para STESIN

La web ya está lista para usar un dominio institucional. Esta configuración no se puede hacer solo con código: requiere que compres o controles un dominio, por ejemplo `stesin.edu.pe`.

1. En GitHub abre **Settings → Pages → Custom domain**.
2. Escribe el dominio que hayas comprado y guarda el cambio.
3. En la empresa donde compraste el dominio, crea los registros DNS indicados por GitHub Pages.
4. Espera la validación del certificado HTTPS.
5. En Firebase abre **Authentication → Configuración → Dominios autorizados** y agrega el nuevo dominio.

No retires el dominio actual de GitHub Pages hasta confirmar que el nuevo dominio funciona correctamente.
