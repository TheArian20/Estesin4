# STESIN · publicación para GitHub Pages

Esta carpeta está preparada para publicarse como repositorio independiente en GitHub Pages. `index.html` está en la raíz y no contiene la biblioteca local de gran tamaño.

En GitHub, crea o usa un repositorio, sube **el contenido de esta carpeta** y en **Settings → Pages** selecciona la rama principal y la carpeta **/(root)**.

La Biblioteca conserva su catálogo, pero las descargas se muestran como próximas porque los archivos originales superan el límite de GitHub. Cuando estén alojados en Google Drive, OneDrive u otro servicio, se podrán añadir sus enlaces públicos al catálogo.
