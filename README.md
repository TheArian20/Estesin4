# STESIN · publicación para GitHub Pages

Esta carpeta contiene la versión web que se debe publicar desde la rama `gh-pages`. `index.html` está en la raíz, los documentos académicos son archivos reales y no incluye la biblioteca local de gran tamaño.

En GitHub, abre **Settings → Pages** y selecciona la rama **gh-pages** con la carpeta **/(root)**.

La Biblioteca conserva su catálogo, pero las descargas se muestran como próximas porque los archivos originales superan los límites de GitHub Pages. Cuando estén alojados en Google Drive, OneDrive u otro servicio, se podrán añadir sus enlaces públicos al catálogo.

## Servicios actuales

- GitHub Pages publica el sitio desde `gh-pages`.
- Firebase Authentication mantiene una única cuenta administrativa.
- Cloud Firestore almacena los registros académicos y las estadísticas anónimas.
- Los estudiantes consultan el contenido público sin crear una cuenta.
- Los archivos pesados se comparten mediante enlaces de Google Drive.

Las pantallas personales de estudiantes, docentes y rectorado se conservan para una etapa futura, pero sus cuentas no están habilitadas actualmente.
